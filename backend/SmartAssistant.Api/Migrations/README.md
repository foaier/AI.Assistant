# SQLite 初始化结构

开发阶段仅维护 `001_initial.sql`，直接创建当前完整结构，不保留历史升级脚本和旧校验值兼容。

脚本包含 20 张业务表、领域事件发件箱和两张本地向量表，共 23 张表、42 个显式索引。字段、索引和外键均有中文多行注释。当前结构直接采用物理删除及外键级联，不包含通用审计、租户、组织和操作人字段。

`LocalDatabase.Migrate` 在单个事务中执行初始化，并在 `assistant_schema_migration` 记录脚本名、SHA256 和本地执行时间。重复启动仅校验当前记录，初始化不会重复执行；结构或校验值不一致时，开发数据库需要重建。

修改结构时直接维护初始化脚本，并同步更新 `Platform/Persistence.cs` 中的 SHA256。SQL 文件统一使用 UTF-8 和 LF 换行。

当前 SHA256：`353b344c285e184536a118871ffbe8cac9a286c249048cb1665e2b663d65e925`。

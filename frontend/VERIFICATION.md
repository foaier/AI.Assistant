# 前端抽离验证

日期：2026-11-11（Asia/Shanghai）。

验证范围覆盖原 Assistant 的管理、工作台、公开聊天、知识库、模型服务、模型策略、发布和传输协议；原始文件校验值见 `source-manifest.json`。

## 结果

- `pnpm install --frozen-lockfile`：通过。
- `pnpm build`：通过严格 TypeScript 检查与 Vite 生产构建，生成 `dist/`。
- `pnpm test`：17 个测试文件、156 / 156 通过；包含 151 个原助手测试及 5 个独立 API 传输测试。
- 开发服务 `http://127.0.0.1:5188/`：HTTP 200。
- `pnpm test:e2e`：6 / 6 通过；桌面 Chrome 和 iPhone 13 Chromium 真实浏览器连接独立后端。覆盖直接进入工作台、无 Cookie 的管理 API、创建/保存/刷新助手、知识库与固定问答、模型策略/服务导航、匿名聊天、刷新恢复和撤回发布。页面不出现登录/退出控件，也不请求 `/api/auth/*`；截图见 `test-results/`，报告见 `playwright-report/index.html`。

原助手测试涵盖创建与字段校验、草稿编辑与预览、取消和恢复流式聊天、历史记录、发布校验、知识库问答与文档处理、Embedding 配置、模型凭证和服务权限。独立 API 测试涵盖无凭据请求、`returnObj` 业务响应拆包、并发冲突与业务错误、401 原地报错及 multipart 边界。

## 抽离适配

- 独立 Vite 入口与导航，打开首页直接进入助手工作台。
- 管理界面使用固定的 `assistant-local` 单组织权限范围，API 不发送 Cookie，不调用登录接口或跳转到登录页；公开聊天继续使用原匿名 Bearer 会话。
- API 管理前缀继续为 `/api/admin`，图片上传适配为 `/api/assets/upload`。
- 提取原助手翻译与时区工具，维持 `Asia/Shanghai` 显示约定。
- 保留所有原始助手测试的断言；仅补充严格 TypeScript 所需的字典索引类型和异步赋值声明。运行时代码仅对已校验 runId 做闭包捕获、超时句柄加空初始化类型，防止严格类型检查误用未定义值。
- 直接依赖版本固定到原锁文件版本，并统一 Vite 依赖，保证提取时不混入依赖升级。

本项单元测试不调用真实模型供应商。模型端到端调用需为独立后端配置模型服务及密钥。

公开聊天浏览器验收使用真实知识库固定问答路径，问题完全匹配时由原助手运行器直接回复，不调用模型。发布绑定的测试模型配置使用不可达的本机 loopback HTTPS 地址，仅为满足配置契约；该测试不声称验证了外部 LLM。助手发布、匿名会话、消息提交、流事件、消息落库、刷新恢复和撤回均走真实独立服务。本轮验收数据限定在 `.run/no-login-browser-data`。
